Website Archives

Complete collection of preserved Rockstar Games websites from 1997 to present. Browse interactive recreations and historical snapshots of official game websites.

See UI Free Version Flash Loader

RUFFLE ERROR = The website wont function correctly because of an issue with our Adobe Flash emulator Ruffle.

INCOMPLETE = Major files of this website are lost making it not completely functional.

Our website uses Ruffle to emulate all Flash games.

Some Adobe Flash files are edited (the unedited files are saved in an unedited folder in the same path).

We try not to edit the original code except adding our JS loader (rgPatcher.js) and fixing paths.

Some sites use their own version of rgPatcher.js with custom redirects.

Very old websites used .ram files (these streamed audio from a different domain). These were replaced with the actual files.

Thanks to the Internet Archive Wayback Machine for archiving almost all of the files used here, and the internet in general. You can donate to them here.

Thanks to Ruffle for creating the Adobe Flash emulator that runs almost everything on this website. You can donate to them here.

Thanks to Rockstar Nexus’s "Unofficial Rockstar Games Museum" for archiving many lost files and websites not available on the Wayback Machine, and also for the rgLoader.js, which is based on their script. Check it out here.

Thanks to the Flashpoint Archive for archiving some of the websites, especially the Midnight Club 3 website. You can donate to them here.

Thanks to our Discord community for recommending sites and providing archives to us.
